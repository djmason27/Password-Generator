## Conversation

### Student prompt

> Create a password generator, you can choose if you want it as an object or a
> function. Regardless, the generator should ask the format for password type,
> either memorable or random.
>
> A memorable password is generated by selecting n random words, adding a random
> 1 digit number to each word, and then concatenating them using a hyphen (-). A
> memorable password should include arguments specifying the number of words and
> the available cases for those words. A list of available words can be downloaded
> as top_english_nouns_lower_100000.txt.
>
> A random password is generated by selecting n random characters from among
> lower case, upper case, numbers, and/or punctuation symbols. A random password
> should include arguments specifying the password length, whether punctuation is
> included, and any characters that are not allowed.
>
> When a password is generated, append the password and creation time (day, date,
> and time) to Generated_Passwords.txt. Both types should have their own file in
> directories named Memorable and Random. Create missing directories. Confirm it
> works by generating 1,000 passwords with the type selected randomly.
>
> Write a README explaining the project purpose, use, input, output, and modules.
> The submission should be a public GitHub repository.

### ChatGPT response and assistance

ChatGPT created a Python project containing:

- An object-oriented `PasswordGenerator` class
- An interactive program that asks the user to select a password type
- Methods for memorable and random passwords with the required arguments
- Automatic directory creation and timestamped password logging
- A script that randomly generates 1,000 passwords of both types
- Unit tests and a README

ChatGPT used the Python standard-library `secrets` module to make random choices,
`string` for character groups, `datetime` for timestamps, and `pathlib` for file
paths. ChatGPT tested the program and reported that all three tests passed. The
1,000-password verification generated 495 memorable passwords and 505 random
passwords.
